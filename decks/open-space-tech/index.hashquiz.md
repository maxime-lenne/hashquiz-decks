## Sur le web, que signifie une erreur 404 ?

- [x] La page est introuvable
- [ ] Le serveur est en panne
- [ ] L'accès est interdit
- [ ] La connexion est trop lente

> **404 Not Found** : le serveur répond bien, mais la page demandée n'existe pas (ou plus). Une panne côté serveur
> donne plutôt une erreur 500, un accès refusé une 403.

## Lesquels sont de vrais codes HTTP ? (sélectionnez 3)

- [x] 200 OK
- [x] 404 Not Found
- [x] 418 I'm a teapot
- [ ] 299 Coffee Break

> **418 I'm a teapot** vient d'un poisson d'avril de 1998 (RFC 2324) : une théière qui refuse de faire du café. Il est
> toujours réservé dans la norme HTTP ! **299 Coffee Break**, lui, n'existe pas.

## En quoi consiste le « rubber duck debugging » ?

- [x] Expliquer son code à voix haute à un canard en plastique
- [ ] Lancer ses tests dans son bain
- [ ] Faire relire son code par un stagiaire
- [ ] Supprimer le code jusqu'à ce que le bug disparaisse

> En expliquant son code ligne par ligne à un **canard en plastique**, on trouve souvent le bug tout seul. La méthode
> vient du livre The Pragmatic Programmer (1999).

## Que signifie PEBKAC, le diagnostic préféré du support informatique ?

- [x] Le problème se situe entre la chaise et le clavier
- [ ] Le câble réseau est débranché
- [ ] Le PC a besoin d'être redémarré
- [ ] Le pilote de l'imprimante est trop vieux

> **PEBKAC** = « Problem Exists Between Keyboard And Chair ». Autrement dit : c'est l'utilisateur. Un classique, avec
> son cousin « erreur ID-10-T ».

## Dans le monde des startups, qu'appelle-t-on une « licorne » ?

- [x] Une startup non cotée valorisée plus d'un milliard de dollars
- [ ] Une startup qui n'a jamais levé de fonds
- [ ] Un fondateur qui code, vend et recrute à la fois
- [ ] Une application téléchargée un million de fois

> Le terme a été inventé en 2013 par l'investisseuse Aileen Lee, car ces startups étaient alors aussi rares qu'une
> **licorne**. En France, on pense à BlaBlaCar, Doctolib ou Mistral AI.

## Quel est, année après année, l'un des mots de passe les plus utilisés au monde ?

- [x] 123456
- [ ] azerty2000
- [ ] MotDePasse!
- [ ] 0000

> **123456** truste le haut des classements des mots de passe les plus fuités, avec « password » et « qwerty ». Il se
> casse en moins d'une seconde : vive le gestionnaire de mots de passe.

## Selon le guide Scrum, combien de temps doit durer le daily (la réunion quotidienne) au maximum ?

- [x] 15 minutes
- [ ] 5 minutes
- [ ] 30 minutes
- [ ] 1 heure, café compris

> Le **Daily Scrum** est limité à **15 minutes**. On le fait souvent debout (« stand-up ») pour s'assurer qu'il ne
> s'éternise pas.

## Quel outil est souvent présenté comme la réponse au fameux « ça marche sur ma machine » ?

- [x] Docker
- [ ] Excel
- [ ] Slack
- [ ] PowerPoint

> **Docker** emballe une application avec tout son environnement dans un conteneur, qui tourne de la même façon sur le
> poste du dev, en test et en production. La blague dit qu'on a fini par livrer la machine du dev.

## Pourquoi évite-t-on traditionnellement de mettre en production le vendredi après-midi ?

- [x] Pour ne pas passer son week-end à réparer un incident
- [ ] Parce que les serveurs sont moins puissants le vendredi
- [ ] Parce que c'est interdit par la loi
- [ ] Parce qu'internet est plus lent le week-end

> Si une mise en production casse quelque chose vendredi à 17 h, l'équipe risque d'y passer le week-end. D'où le
> dicton « Don't deploy on Friday ».

## Que signifie MVP dans une startup ?

- [x] Minimum Viable Product
- [ ] Most Valuable Player
- [ ] Maximum Value Project
- [ ] Main Version in Production

> Le **MVP** (produit minimum viable) est la version la plus simple d'un produit qui permet de tester l'idée auprès de
> vrais utilisateurs. Rien à voir avec le meilleur joueur du match... même si l'équipe qui le livre mérite le titre.

## Comment appelle-t-on un événement de 24 à 48 heures où des équipes construisent un prototype à toute vitesse ?

- [x] Un hackathon
- [ ] Un bootcamp
- [ ] Un séminaire
- [ ] Un marathon produit

> Le **hackathon** (contraction de *hack* et *marathon*) mêle pizzas, nuits blanches et démos de dernière minute
> devant un jury. Un **bootcamp**, lui, est une formation intensive de quelques semaines.

## À la fin d'un sprint, comment s'appelle le rituel où l'équipe parle de ce qui a bien ou mal marché ?

- [x] La rétrospective
- [ ] La démo
- [ ] Le daily
- [ ] Le planning

> La **rétro** sert à améliorer la façon de travailler ensemble, souvent avec des post-its « on garde / on arrête / on
> essaie ». La **démo** montre le produit, le **daily** synchronise l'équipe chaque jour et le **planning** prépare le
> sprint suivant.

## Quelle suite de nombres retrouve-t-on souvent sur les cartes du planning poker ?

- [x] La suite de Fibonacci (1, 2, 3, 5, 8, 13...)
- [ ] Les nombres premiers (2, 3, 5, 7, 11...)
- [ ] Les puissances de 10 (1, 10, 100...)
- [ ] Les multiples de 5 (5, 10, 15...)

> Avec la suite de **Fibonacci**, plus une tâche est grosse, plus l'écart entre deux cartes grandit : une bonne façon
> de rappeler qu'une grosse estimation est forcément incertaine. Et il y a souvent une carte café.

## Comment s'appelle le tableau en colonnes « À faire / En cours / Terminé » qu'on retrouve dans tant d'équipes ?

- [x] Un tableau Kanban
- [ ] Un diagramme de Gantt
- [ ] Un mur de Scrum
- [ ] Un tableau croisé dynamique

> **Kanban** signifie « étiquette » ou « panneau » en japonais. La méthode vient des usines **Toyota** dans les années
> 50, bien avant les post-its numériques de Trello et Jira.

## Dans une équipe, que désigne l'« onboarding » ?

- [x] L'accueil et l'intégration d'un nouvel arrivant
- [ ] La mise en ligne d'une nouvelle application
- [ ] L'embarquement pour un séminaire d'équipe
- [ ] La signature d'un nouveau client

> L'**onboarding** couvre tout ce qui aide un nouveau à trouver sa place : son poste prêt le premier jour, ses accès,
> un parrain ou une marraine... et le premier café avec l'équipe.
